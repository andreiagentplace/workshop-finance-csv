# Prompt

Создай полный проект веб-приложения на React + Vite.

Цель:
Сделать простой веб-сервис для анализа банковской CSV-выписки.
Это учебный проект для воркшопа: человек должен понять путь от идеи
и промпта до GitHub и деплоя на Vercel.

Ограничения:
- Без backend.
- Без базы данных.
- Без API-ключей.
- Без платных сервисов.
- Всё должно работать только в браузере.
- CSV-данные не должны отправляться на сервер.
- Проект должен быть готов для деплоя на Vercel.
- Используй React и обычный CSS.
- Без TypeScript.
- Без Tailwind.
- Без сложных библиотек.
- Дизайн: современный, чистый, с аккуратными карточками,
  приятными цветами и нормальными отступами.
  Без внешних CSS-библиотек.

Формат CSV:
date,description,amount,currency

Пример данных:
2026-05-01,Salary,3500,EUR
2026-05-02,Biedronka,-45.90,EUR
2026-05-03,Uber,-12.50,EUR
2026-05-04,Netflix,-15.99,EUR
2026-05-05,Rent,-1200,EUR
2026-05-06,Pharmacy,-24.30,EUR
2026-05-07,Restaurant,-67.40,EUR

Функции приложения:
1. Загрузка CSV-файла.
2. Кнопка "Загрузить демо-данные".
3. Автоматическая классификация операций:
   - Доход
   - Продукты
   - Транспорт
   - Жильё
   - Подписки
   - Здоровье
   - Рестораны
   - Другое
4. Dashboard-карточки:
   - общий доход
   - общие расходы
   - баланс
5. Блок "Расходы по категориям".
6. Блок "Топ-5 расходов".
7. Таблица всех транзакций.
8. Блок "Выводы" с 3 простыми финансовыми наблюдениями.
9. Современный, чистый, адаптивный интерфейс.
10. README с инструкцией, как запустить и задеплоить проект на Vercel.
11. PROMPT.md с промптом, который использовался для создания проекта.

Выдай полный результат строго по файлам:
1. package.json
2. index.html
3. src/main.jsx
4. src/App.jsx
5. src/index.css
6. README.md
7. PROMPT.md

Для каждого файла сначала напиши путь файла, потом полный код.
Не сокращай код, не пропускай части. Каждый файл — полностью.
Без вступлений, объяснений и технических комментариев. Сразу файлы в zip архиве.
