# Bank CSV Analyzer v2

Простое учебное веб-приложение на React + Vite для анализа банковской CSV-выписки.

Приложение работает полностью в браузере:
- без backend;
- без базы данных;
- без API-ключей;
- без отправки CSV-данных на сервер.

## Что умеет приложение

- Загружать CSV-файл.
- Загружать демо-данные.
- Автоматически определять разделитель:
  - запятая;
  - точка с запятой;
  - tab.
- Читать UTF-8 и Windows-1250.
- Распознавать разные названия колонок на английском, польском и русском языках.
- Поддерживать суммы в разных форматах:
  - `-45.90`;
  - `-45,90`;
  - `1 200,50`;
  - `1200.50`.
- Автоматически классифицировать операции.
- Показывать общий доход.
- Показывать общие расходы.
- Считать баланс.
- Показывать расходы по категориям.
- Показывать топ-5 расходов.
- Показывать таблицу всех транзакций.
- Формировать 3 простых финансовых наблюдения.
- Показывать информацию об источнике данных:
  - имя файла;
  - количество операций;
  - распознанный разделитель;
  - распознанную кодировку.

## Поддерживаемые колонки

Обязательные колонки:
- дата;
- описание;
- сумма.

Валюта необязательна.

### Дата

Поддерживаемые названия:
- `date`;
- `data`;
- `data operacji`;
- `transaction date`;
- `дата`.

### Описание

Поддерживаемые названия:
- `description`;
- `opis`;
- `opis operacji`;
- `opis transakcji`;
- `merchant`;
- `details`;
- `описание`.

### Сумма

Поддерживаемые названия:
- `amount`;
- `kwota`;
- `kwota operacji`;
- `value`;
- `suma`;
- `сумма`.

### Валюта

Поддерживаемые названия:
- `currency`;
- `waluta`;
- `curr`;
- `ccy`;
- `валюта`.

## Пример CSV

```csv
date,description,amount,currency
2026-05-01,Salary,3500,EUR
2026-05-02,Biedronka,-45.90,EUR
2026-05-03,Uber,-12.50,EUR
2026-05-04,Netflix,-15.99,EUR
2026-05-05,Rent,-1200,EUR
2026-05-06,Pharmacy,-24.30,EUR
2026-05-07,Restaurant,-67.40,EUR
```

Положительные суммы считаются доходами. Отрицательные суммы считаются расходами.

## Как запустить локально

1. Установите Node.js.
2. Откройте папку проекта.
3. Установите зависимости:

```bash
npm install
```

4. Запустите проект:

```bash
npm run dev
```

5. Откройте ссылку, которую покажет Vite.

## Как собрать проект

```bash
npm run build
```

Готовая сборка появится в папке `dist`.

## Как задеплоить на Vercel через GitHub

1. Создайте новый репозиторий на GitHub.
2. Загрузите все файлы проекта в репозиторий.
3. Откройте Vercel.
4. Нажмите Add New Project.
5. Выберите GitHub-репозиторий.
6. Framework Preset должен определиться как Vite.
7. Нажмите Deploy.

После деплоя Vercel выдаст публичную ссылку на приложение.
